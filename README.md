# AI-Powered Symptom Assessment Chatbot - Thesis Project

## 🎓 Thesis Project Overview
**Title:** Development of an AI-powered chatbot for preliminary symptom assessments via command-line interface

**Research Focus:**
- Increasing early health awareness in areas with limited healthcare access
- Command-line interface for low-resource environments
- Rule-based logic combined with natural language processing
- Ethical considerations in non-clinical diagnostics
- Complementing formal healthcare systems

## 🤖 Project Implementation
This repository contains the complete implementation of my thesis project, demonstrating:

### 1. **AI Chatbot Core**
- `chatbot/cli/chatbot.py` - Main chatbot implementation
- Rule-based symptom matching
- Basic NLP for symptom interpretation
- Ethical framework integration

### 2. **Command-Line Interface**
- Designed for terminal/SSH access
- No GUI dependencies
- Suitable for limited-resource environments

### 3. **DevOps Integration**
- Virtual environment for reproducibility
- Automated testing framework
- Version control with Git
- Professional project structure
